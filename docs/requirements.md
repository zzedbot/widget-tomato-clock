# 番茄伴侣 Windows 桌面挂件需求说明

> 文档版本：v0.1  
> 产品阶段：MVP 原型  
> 视觉方向：B — 温暖、克制的番茄角色  
> 目标平台：Windows 10 / Windows 11

## 1. 产品概述

“番茄伴侣”是一款常驻 Windows 桌面的轻量番茄钟挂件。它帮助用户快速开始一段专注时间、在工作与休息间自然切换，并通过一个安静的小番茄角色提供适度陪伴感。

产品强调三点：

- 一眼看清剩余时间；
- 一次点击开始或暂停；
- 常驻桌面，但不过度打扰当前工作。

## 2. 产品目标

### 2.1 核心目标

- 降低开始专注任务的操作成本；
- 用清晰的计时状态帮助用户建立工作与休息节奏；
- 允许用户在不中断当前工作的情况下控制计时器；
- 提供轻量、温暖且适合成年人使用的角色化体验。

### 2.2 MVP 成功标准

- 用户启动应用后，最多一次点击即可开始默认的 25 分钟专注；
- 计时状态在挂件、系统通知和托盘菜单中保持一致；
- 应用重启或系统重启后，不会错误重置正在进行的计时；
- 主挂件在常见 Windows 缩放比例下均可正常阅读和操作；
- 核心计时功能离线可用。

## 3. 目标用户与使用场景

### 3.1 目标用户

- 需要长时间专注的开发者、设计师、写作者和学生；
- 容易拖延，希望通过短周期开始任务的用户；
- 希望计时工具常驻桌面，但不喜欢复杂效率软件的用户。

### 3.2 典型场景

1. 用户开始工作前输入“整理项目方案”，点击“开始专注”。
2. 专注开始后，挂件自动收起为迷你模式，不遮挡主要工作窗口。
3. 专注结束时，系统发出声音和通知，引导用户进入短休息。
4. 完成四轮专注后，系统建议进入长休息。
5. 用户通过托盘图标快速暂停、继续或跳过当前阶段。

## 4. 产品范围

### 4.1 MVP 范围

- 番茄钟倒计时；
- 专注、短休息和长休息循环；
- 当前任务输入与编辑；
- 开始、暂停、继续、重置和跳过；
- 今日番茄完成数量；
- 主挂件与迷你挂件模式；
- 始终置顶与窗口拖拽；
- 系统托盘菜单；
- 声音与 Windows 系统通知；
- 计时参数及基础应用设置；
- 本地状态保存与异常恢复；
- 开机自动启动。

### 4.2 暂不纳入 MVP

- 登录、账号体系和云同步；
- 多设备同步；
- 团队协作或排行榜；
- 完整任务管理、项目管理或日历；
- 跨平台版本；
- 复杂统计报表；
- 第三方服务集成；
- 角色皮肤商城或付费系统。

## 5. 信息架构

应用由以下界面组成：

- **主挂件**：显示状态、剩余时间、当前任务和核心操作；
- **迷你挂件**：显示角色、剩余时间、任务摘要和暂停/继续；
- **设置面板**：设置时长、循环、自动化、声音和窗口行为；
- **系统托盘菜单**：快速显示、隐藏和控制计时器；
- **系统通知**：提示专注或休息结束。

## 6. 功能需求

### 6.1 计时器

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-T01 | 默认专注时长为 25 分钟 | P0 |
| FR-T02 | 默认短休息时长为 5 分钟 | P0 |
| FR-T03 | 默认长休息时长为 15 分钟 | P0 |
| FR-T04 | 默认每完成 4 次专注后进入长休息 | P0 |
| FR-T05 | 用户可开始、暂停、继续、重置或跳过当前阶段 | P0 |
| FR-T06 | 倒计时显示到秒，并使用等宽数字避免布局跳动 | P0 |
| FR-T07 | 倒计时以系统时间为基准计算，不依赖固定间隔累减 | P0 |
| FR-T08 | 系统休眠或应用短暂挂起后，应根据目标结束时间恢复正确剩余时间 | P0 |
| FR-T09 | 计时归零后只触发一次阶段完成事件 | P0 |
| FR-T10 | 用户可在设置中修改各阶段时长和长休息间隔 | P0 |

### 6.2 计时状态

系统包含以下状态：

| 状态 | 说明 | 主操作 | 强调色 |
| --- | --- | --- | --- |
| 待开始 | 尚未启动当前专注 | 开始专注 | 番茄红 |
| 专注中 | 专注倒计时运行 | 暂停 | 番茄红 |
| 已暂停 | 倒计时停止，保留剩余时间 | 继续专注 | 中性棕 |
| 短休息 | 普通专注轮次后的短休息 | 提前结束休息 | 叶片绿 |
| 长休息 | 完成设定轮次后的长休息 | 提前结束休息 | 叶片绿 |
| 已完成 | 当前阶段刚刚结束 | 开始下一阶段 | 番茄红或叶片绿 |

状态转换规则：

```text
待开始 → 专注中 ⇄ 已暂停
专注中 → 专注完成 → 短休息或长休息
短休息/长休息 ⇄ 已暂停
短休息/长休息 → 休息完成 → 待开始
任意运行状态 → 重置 → 对应阶段的待开始状态
任意运行状态 → 跳过 → 下一阶段
```

补充规则：

- 专注完成后，今日完成数量加一；
- 跳过专注不计入完成数量；
- 重置只重置当前阶段，不改变今日完成数量；
- 是否自动开始下一阶段由用户设置决定；
- 状态不能只依赖颜色表达，必须同时显示文字或图标。

### 6.3 当前任务

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-K01 | 用户可在待开始或暂停状态编辑当前任务 | P0 |
| FR-K02 | 任务名称允许为空；为空时显示“准备开始专注” | P0 |
| FR-K03 | MVP 建议限制为 80 个字符 | P1 |
| FR-K04 | 过长文本在主挂件和迷你挂件中单行截断，并提供完整内容提示 | P1 |
| FR-K05 | 完成一轮后默认保留当前任务，方便继续下一轮 | P1 |

### 6.4 主挂件

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-W01 | 主挂件为无系统标题栏的圆角窗口 | P0 |
| FR-W02 | 顶部空白区域支持拖拽移动窗口 | P0 |
| FR-W03 | 提供“始终置顶”快捷按钮，并清楚显示启用状态 | P0 |
| FR-W04 | 记住用户最后一次窗口位置 | P1 |
| FR-W05 | 窗口位置恢复时必须位于当前可用屏幕区域内 | P0 |
| FR-W06 | 主挂件显示状态、倒计时、当前任务、今日进度和核心操作 | P0 |
| FR-W07 | 设置按钮打开设置面板 | P0 |
| FR-W08 | 主挂件支持切换为迷你模式 | P0 |

建议设计尺寸约为 392 × 270 像素；实现时应根据 Windows DPI 缩放进行适配，不应将物理像素写死为唯一尺寸。

### 6.5 迷你挂件

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-M01 | 显示番茄角色、剩余时间、任务摘要和暂停/继续按钮 | P0 |
| FR-M02 | 支持拖拽和始终置顶 | P0 |
| FR-M03 | 双击或点击指定区域恢复主挂件 | P1 |
| FR-M04 | 若启用“专注时自动收起”，开始专注后自动进入迷你模式 | P0 |
| FR-M05 | 休息开始或计时结束时可自动恢复主挂件，以便用户确认下一步 | P1 |

### 6.6 设置面板

#### 计时设置

- 专注时长：默认 25 分钟；
- 短休息时长：默认 5 分钟；
- 长休息时长：默认 15 分钟；
- 长休息间隔：默认每 4 次专注。

建议取值范围：

- 专注：1–120 分钟；
- 短休息：1–30 分钟；
- 长休息：1–60 分钟；
- 长休息间隔：1–12 次。

#### 自动化设置

- 自动开始休息，默认开启；
- 自动开始下一轮专注，默认关闭；
- 专注时自动收起挂件，默认开启。

#### 声音与系统设置

- 提醒声音开关，默认开启；
- 提醒声音选择；
- 音量调节，默认 80%；
- 始终置顶，默认开启；
- 开机自动启动，默认关闭；
- 恢复默认设置。

设置保存规则：

- 修改后点击“保存设置”生效；
- 对正在运行的阶段，时长修改从下一阶段开始生效；
- 恢复默认设置必须进行二次确认；
- 设置保存失败时应保留用户当前输入并给出错误提示。

### 6.7 系统托盘

系统托盘菜单至少包含：

- 显示/隐藏挂件；
- 当前状态与剩余时间；
- 开始/暂停/继续；
- 跳过当前阶段；
- 始终置顶开关；
- 打开设置；
- 退出应用。

点击窗口关闭按钮时，默认隐藏到系统托盘，不直接退出应用。用户选择“退出应用”时，如果计时正在运行，应进行确认。

### 6.8 提醒与通知

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-N01 | 专注或休息结束时播放一次提醒声音 | P0 |
| FR-N02 | 专注或休息结束时发送 Windows 系统通知 | P0 |
| FR-N03 | 通知文案必须明确当前完成事件和建议的下一步 | P0 |
| FR-N04 | 点击通知应显示主挂件或执行明确的通知操作 | P1 |
| FR-N05 | 通知不得因页面刷新或状态恢复而重复发送 | P0 |

建议通知文案：

- 专注结束：“完成一个番茄，休息一下吧。”
- 短休息结束：“休息结束，准备开始下一轮专注。”
- 长休息结束：“状态恢复得不错，开始新的专注循环吧。”

## 7. 角色与动效需求

番茄角色的作用是表达状态，不应抢占用户注意力。

- 待开始：安静等待；
- 开始专注：一次轻微点头或缩放反馈；
- 专注中：保持静止；
- 暂停：表情变为等待；
- 休息：闭眼或放松状态；
- 完成：播放一次短暂庆祝反馈，随后停止。

动效时长建议为 160–220 毫秒。应用必须读取 Windows 的“减少动画”偏好；启用后移除庆祝、弹跳和持续脉冲，仅保留必要的状态变化。

## 8. 数据与本地存储

### 8.1 需要持久化的数据

- 当前阶段类型；
- 当前阶段状态；
- 当前阶段开始时间和目标结束时间；
- 暂停时的剩余时长；
- 当前任务；
- 今日完成数量及对应日期；
- 用户设置；
- 主挂件/迷你模式；
- 窗口位置；
- 最近一次已处理的完成事件标识。

### 8.2 数据规则

- 数据仅保存在用户本机；
- MVP 不要求账号或网络连接；
- 日期变化后，今日完成数量归零；
- 应用意外退出后重新打开，应恢复合理状态；
- 若目标结束时间已过去，应进入完成后的正确阶段，且只提醒一次。

## 9. 非功能需求

### 9.1 性能

- 冷启动目标不超过 2 秒；
- 空闲状态下不应持续高频刷新；
- 倒计时显示可每秒更新，但实际剩余时间以系统时间差计算；
- 常驻内存与 CPU 占用应保持在桌面小工具的合理范围。

### 9.2 兼容性

- 支持 Windows 10 22H2 及 Windows 11；
- 支持 100%、125%、150% 和 200% DPI 缩放；
- 支持多显示器及显示器热插拔；
- 系统休眠、锁屏和唤醒后应正确恢复。

### 9.3 可访问性

- 正文和关键控件满足 WCAG AA 对比度；
- 所有操作可通过键盘完成；
- 焦点状态清晰可见；
- 图标按钮提供可访问名称和悬停提示；
- 不仅使用颜色区分专注、暂停和休息；
- 支持 Windows 减少动画设置。

### 9.4 隐私与安全

- 不收集或上传用户任务内容；
- 不要求管理员权限运行；
- 开机启动应使用 Windows 推荐机制并允许随时关闭；
- 卸载后不保留无必要的后台进程。

## 10. 异常与边界情况

- 用户修改系统时间时，应避免倒计时出现明显负数或重复完成；
- 电脑休眠超过当前阶段结束时间时，唤醒后应进入正确状态；
- 恢复窗口位置时，如果原显示器不存在，应移动到主显示器可见区域；
- 提醒音频文件缺失时，应回退为系统提示音或仅发送通知；
- 通知权限关闭时，核心计时功能必须继续工作；
- 重复快速点击开始/暂停不得创建多个并行计时任务；
- 剩余时间不得显示为负数；
- 应用仅允许一个主实例运行。

## 11. MVP 验收标准

### 11.1 核心流程

- [ ] 启动应用后显示待开始状态和默认 25:00；
- [ ] 点击“开始专注”后，倒计时正确运行；
- [ ] 暂停后时间停止，继续后从原剩余时间运行；
- [ ] 专注结束后今日完成数量加一；
- [ ] 前三次专注完成后进入短休息，第四次进入长休息；
- [ ] 跳过专注不增加完成数量；
- [ ] 重置后回到当前阶段的初始时长；
- [ ] 计时结束只发送一次声音和系统通知。

### 11.2 桌面体验

- [ ] 主挂件可以拖拽、置顶、隐藏和恢复；
- [ ] 迷你模式可以正常显示剩余时间并暂停/继续；
- [ ] 开启自动收起后，开始专注会进入迷你模式；
- [ ] 多显示器或 DPI 改变后窗口仍然可见；
- [ ] 关闭窗口后应用保留在系统托盘；
- [ ] 托盘菜单中的状态与主挂件一致。

### 11.3 设置与恢复

- [ ] 所有 MVP 设置可以保存并在重启后恢复；
- [ ] 修改计时时长不会破坏正在进行的阶段；
- [ ] 异常退出或系统重启后可恢复计时；
- [ ] 恢复默认设置需要确认；
- [ ] 无网络环境下核心功能可正常使用。

## 12. 开发优先级建议

### 第一阶段：核心计时

- 状态机与基于目标时间的倒计时；
- 开始、暂停、继续、重置和跳过；
- 本地持久化与异常恢复；
- 今日完成数量。

### 第二阶段：桌面体验

- 无边框主挂件；
- 拖拽、置顶、迷你模式；
- 系统托盘；
- 多显示器与 DPI 适配。

### 第三阶段：设置与提醒

- 设置面板；
- 系统通知与提醒声音；
- 自动开始与自动收起；
- 开机自动启动。

### 第四阶段：体验完善

- 番茄角色状态与轻量动效；
- 键盘操作和可访问性；
- 异常场景测试；
- 安装包与升级策略。

## 13. 待确认事项

- Windows 客户端技术栈选择；
- 是否支持用户导入自定义提醒声音；
- 每日完成数量的日期切换规则是否固定为本地零点；
- 退出应用时是否默认确认，或允许用户关闭确认；
- MVP 是否需要最近 7 天的简单完成记录；
- 产品正式名称与应用图标方案。
