# 番茄钟 × 待办功能设计

> 阶段：Windows MVP 已实现
> 核心原则：待办决定“这段时间花在哪里”，番茄钟负责“这段时间如何被切分”。

## 1. 待办模型

### 长期待办

- 通常跨越一天以上，是一个结果或目标，例如“完成新版产品方案”；
- 可以包含若干短期待办；
- 显示累计专注时间、目标日期和未完成短待办数量；
- 一个番茄会话可以选择多个长期待办作为范围，但任一时刻只有一个“当前长期目标”。

### 短期待办

- 通常在几分钟到几小时内完成，是可直接执行的动作；
- 可以隶属于某个长期待办，也可以独立存在；
- 一个会话可选择多个短期待办组成执行队列；
- 任一时刻只有一个短期待办处于“正在计时”。

## 2. 时间归集原则

为了避免同一分钟被重复记入多个待办，采用“单一计时归属 + 长期目标汇总”模型：

1. 每个会话可以选择多个待办，但必须指定一个当前计时待办；
2. 存在正在执行的短期待办时，时间直接记入该短期待办；
3. 该短期待办属于长期目标时，长期目标的耗时通过子待办汇总得出，不额外创建重复时间；
4. 只选择长期待办时，时间可以直接记入该长期待办；
5. 暂停和休息时间不计入待办耗时；
6. 切换任务、暂停、计时结束或 Punch 时关闭当前时间片，再开启下一时间片。

界面可以同时显示：`本轮 18m · 累计 2h 35m`。其中“本轮”来自当前番茄内的时间片，“累计”来自历史有效时间片求和。

## 3. 开始番茄

点击“开始专注”时：

- 没有已选待办：打开待办选择面板，开始按钮禁用，并提示“至少选择 1 项”；
- 已选择待办：必须明确一个当前计时项，之后才可开始；
- 支持同时选择长期和短期待办；
- 长期待办使用叶片绿标签，短期待办使用番茄红标签；
- 支持在选择面板内快速新建短期待办。

推荐的选择结构：

```text
本轮专注 25:00                    3 项已选择

长期待办
  ☑ 完成新版产品方案       [当前目标]
  ☐ 准备季度复盘           [长期]

短期待办
  ☑ 梳理核心目标与范围     [首先执行]
  ☑ 补充里程碑和负责人
  ☐ 发送评审邀请

[开始专注 · 3 项]
```

## 4. 运行期间

计时器仍是第一视觉层级，待办区域只显示当前上下文和队列：

- 当前长期目标：名称、累计耗时、“更换”入口；
- 当前短期待办：名称、本轮耗时、累计耗时、Punch；
- 本轮队列：后续已选短期待办；
- “添加短待办”：不暂停番茄，可直接加入队列；
- 更换长期待办：立即关闭旧时间片并创建新时间片，不重置番茄倒计时。

如果当前短期待办隶属于旧长期目标，更换长期目标时需要用户选择：

- 将当前短待办一起移动到新长期目标；或
- 暂存当前短待办，并从新长期目标下选择新的执行项。

## 5. Punch

`Punch` 是用户主动确认待办完成的动作，不等同于番茄结束。

Punch 当前任务时：

1. 关闭当前时间片；
2. 将待办状态改为已完成；
3. 写入 Punch 记录，包括完成时间、直接耗时和所属会话；
4. 显示短暂反馈，例如“已 Punch · 记录专注 18 分钟”；
5. 队列仍有任务时自动把下一项设为当前任务；
6. 队列为空时番茄继续运行，但提示用户选择新任务或结束本轮。

Punch 非当前任务时只改变完成状态，并记录此前已经产生的耗时，不把当前时间片错误归入该任务。

Punch 长期待办时，如仍有未完成的短期待办，需要二次确认；未完成子项默认保留并解除归属，不自动删除。

## 6. 界面层级

### 主挂件

- 保持当前紧凑尺寸；
- 默认展示计时器、当前长期目标、当前短期待办和 Punch；
- 通过“选择/更换待办”打开较高的管理面板；
- 不在主挂件中放完整任务库、统计图或看板。

### 迷你挂件

- 显示倒计时和当前短期待办；
- 保留暂停/继续；
- Punch 需要先展开主挂件，避免误触。

### 停靠番茄

- 保持纯番茄形态；
- 悬停展开后才显示当前任务与 Punch。

## 7. 数据记录

建议的核心实体：

- `Todo`：类型、标题、状态、长期归属、创建/完成时间；
- `FocusSession`：番茄开始、暂停、结束以及已选待办集合；
- `TimeSegment`：开始时间、结束时间、直接归属待办、当时的长期上下文；
- `PunchRecord`：待办、Punch 时间、直接耗时、汇总耗时和来源会话。

时间片账本是耗时的唯一事实来源。待办的“累计耗时”应由时间片求和得到，而不是在多个字段中反复累加。

## 8. 验收规则

- 未选择任何待办不能开始专注；
- 多选待办不会造成时间重复计算；
- 运行中添加短期待办不影响倒计时；
- 更换长期待办不会丢失切换前耗时；
- Punch 后的记录可追溯到具体时间片和番茄会话；
- 暂停、休息和应用关闭期间不产生待办耗时；
- 意外退出恢复后，不生成重叠或重复时间片。
